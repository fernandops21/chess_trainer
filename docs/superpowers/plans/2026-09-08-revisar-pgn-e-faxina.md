# Menu "Revisar", importação de PGN e faxina dos parcados — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** (1) A repetição espaçada ganha um item de menu próprio, "Revisar", que abre direto a fila de vencidos de todas as fontes, com o badge de vencidos explicado; a tela "Nova sessão" deixa de guardar o filtro de fontes e mostra quantos vencidos sobram com os filtros escolhidos; sessões são encerradas ao sair da tela. (2) Importar estudo a partir de um arquivo `.pgn` (livros e coleções de partidas em PGN que o usuário possui), com nomes de capítulo decentes para PGN comum. (3) Faxina dos achados parcados nos followups anteriores.

**Contexto (decidido em conversa, 2026-09-07/08):** o usuário tinha 5 vencidos que a sessão "Repetição espaçada" nunca servia porque o filtro `fontes: estudo` ficava salvo no `localStorage` de uma sessão anterior; o badge do menu contava sem filtro. Conteúdo de livros nunca é distribuído pelo app: cada usuário importa o PGN que possui.

Como o chessground 9.2.1 funciona (conferido em `frontend/node_modules/chessground/dist/svg.js`): `renderShape` desenha a linha reta só quando `shape.brush` está definido; `shape.customSvg = { html, center: "orig" }` é desenhado **além** disso, num `<svg width="1" height="1" viewBox="0 0 100 100">` transladado para o centro da casa de origem (1 unidade = 1 casa; 100 unidades no viewBox = 1 casa; o svg aninhado tem `overflow: visible` no CSS base do chessground em `.cg-wrap .cg-custom-svgs svg` — conferir; senão adicionar em `base.css`). A linha reta usa `stroke-width` = `lineWidth/64` casas (padrão 10/64 ≈ 0,156 casa → 15,6 unidades do viewBox de 100), `stroke-linecap: round`, opacidade do pincel (1), ponta `marker-end="url(#arrowhead-<brush>)"` (os markers ficam nas `<defs>` do svg `.cg-shapes`, no mesmo documento — a referência por id funciona do svg vizinho; se não funcionar no jsdom não importa, só no navegador), e encurta o fim em `arrowMargin` = 10/64 casa (20/64 quando a casa de destino tem mais de uma seta chegando; ignorar esse caso: usar 10/64 sempre). Cores padrão dos pincéis: green `#15781B`, red `#882020`, blue `#003088`, yellow `#e68f00`.
Regra: para uma seta cujo `orig→dest` é lance de cavalo (|Δcoluna|,|Δfileira| = (1,2) ou (2,1)), `decorarCavalo` devolve `{ orig, dest, brush: undefined, customSvg: { html, center: "orig" }, cavalo: brush }` (campo extra `cavalo` guarda o pincel original; tipar com uma interseção local `DrawShape & { cavalo?: string }`). O `html` é um `<path>` em coordenadas do viewBox (origem = centro da casa de origem = (50,50); cada casa = 100 unidades; eixo x cresce para a direita e y para baixo **na tela**, então com orientação `black` os deltas de coluna e fileira invertem de sinal): ramo **longo primeiro** (2 casas), depois o curto (1 casa), terminando `arrowMargin` antes do centro do destino (10/64 casa = 15,6 unidades), `fill="none"`, `stroke` = cor do pincel, `stroke-width="15.6"`, `stroke-linecap="round"`, `stroke-linejoin="round"`, `opacity` do pincel, `marker-end="url(#arrowhead-<brush>)"`. Pincel desconhecido → verde. Setas que não são de cavalo saem intactas.
